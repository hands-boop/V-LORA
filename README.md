# VÉLORA - Modern & Elegant Luxury Fashion

Website portofolio e-commerce busana mewah kontemporer dan haute couture dengan estetika bersih, hangat, dan berkelas.

## ✨ Fitur Utama
- **Desain Modern Elegan**: Palet warna *Warm Silk Alabaster*, *Deep Obsidian Noir*, dan aksen *Brushed Champagne Gold*.
- **Hero Banner Interaktif**: Tampilan model editorial busana dengan floating value badge berkonsep *frosted glass*.
- **Kategori Produk**: Navigasi cepat kategori busana (Pria, Wanita, Sepatu, Tas Mewah, Jam Tangan, Aksesori).
- **Detail Produk / Quick View Modal**: Popup interaktif lengkap dengan pilihan warna, ukuran, stepper kuantitas, deskripsi bahan, dan jaminan produk.
- **Shopping Cart Drawer**: Keranjang belanja samping dengan kalkulator subtotal dan indikator gratis ongkir dinamis.
- **Live Search Overlay**: Pencarian instan produk berdasarkan nama dan kategori.
- **Wishlist**: Simpan busana favorit dengan penyimpanan status real-time.
- **Desain Responsif**: Optimal untuk layar ultrawide, desktop, tablet, maupun smartphone.

## 🚀 Cara Menjalankan
Buka file `index.html` langsung di browser favorit Anda atau jalankan melalui web server lokal.
